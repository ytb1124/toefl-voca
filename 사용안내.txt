TOEFL 오답뱅크 · 가이드 구조 반영 v3
2026-10-17

시작
‘학습 시작.command’를 더블클릭합니다.
http://127.0.0.1:8871/study/index.html 이 열립니다.
학습 중에는 함께 열린 터미널 창을 유지하세요. 종료해도 브라우저 기록은 남습니다.
이전 버전이 같은 주소에서 실행 중이면 이전 학습용 터미널 창을 닫고 다시 시작하세요.
기록을 이어 쓰려면 같은 브라우저·같은 주소를 사용하세요. 주소가 바뀌면 백업을 가져옵니다.

가장 쉬운 사용 순서
1. 내 학습 → 첫 문제 / 이어서 풀기.
2. 문제를 풀고 정답 확인. C-Test 오답 문항은 품사를 먼저 예상할 수 있습니다.
   확신도는 1~5 중 직접 선택하며, 선택하지 않은 값은 미기록으로 남습니다.
3. 틀렸다면 ‘가장 큰 원인’과 ‘다음 문제에서 할 행동’ 두 가지만 확인·저장합니다.
   처음 제시되는 원인·규칙은 추정 제안입니다. 실제 생각과 다르면 수정하세요.
   모르면 ‘아직 원인을 모르겠어요’로 저장할 수 있습니다. 빈칸을 추측으로 채우지 않습니다.
4. 관련 어휘 버튼 → 뜻 회상 → 뜻 확인 → 내 결과 선택.
5. 다음 복습에서 저장한 규칙을 적용해 풉니다.
6. 채점 후 ‘같은 원인으로 다시 틀림 / 규칙 적용 확인 / 다른 원인 / 아직 모름’을 기록합니다.
7. 변화 확인에서 같은 문항의 재발 변화와 새 문제 첫 풀이 결과를 따로 확인합니다.

다섯 메뉴
내 학습: 이어 풀 문제, 오늘 확인할 원인, 약점에 맞는 다음 훈련.
훈련 목록: 원문 재풀이 61개 / 기존 C-Test 49개 Task / 원문 기반 교정 18개 / 직접 제작 신규 연습 28개.
오답뱅크: 문제별 오답 / 교정 규칙 / 연결된 어휘.
변화 확인: 실수 변화 / 최초 시험 성적 / 최근 7일 / 14일 훈련.
학습 기록: 코스별 진도, 풀이 기록, 적용한 규칙과 근거, 백업·가져오기.

문제별 진단
주원인·부원인을 따로 저장합니다. 주원인 통계에서는 한 문항을 한 번만 셉니다.
원보고서 V/G/C/I/J/A/M/T는 보존합니다. 가이드의 세부 코드를 별도로 저장합니다.
원보고서 M은 기억, 가이드 M은 의미입니다. 듣기 기억의 가이드 코드는 LI5입니다.
내 생각, 선택한 이유, 정확한 근거, 내 답과 정답의 차이, 난이도, 듣기 실패 단계·시각을 추가할 수 있습니다.
규칙을 수정해도 예전 풀이가 시작될 때의 규칙은 그대로 남고 변경 이력을 확인할 수 있습니다.
‘원인 미확정’은 재발 통계에 포함하지 않습니다.

어휘
기존 보고서의 학습 후보 65개를 문항과 연결했습니다. 모두 몰랐다고 단정하지 않았습니다.
뜻·문맥의 뜻·품사·혼동 표현·동의어·결합 표현·파생어·연결 문항을 편집할 수 있습니다.
직접 단어를 추가할 수도 있습니다. 원문에서 확인하지 못한 문장은 만들어 넣지 않았습니다.
C-Test에서 틀린 단어는 Task와 연결됩니다. 같은 단어는 여러 Task의 출처를 모읍니다.
뜻 회상은 사용자가 자기평가합니다. 입력한 한국어 뜻을 자동으로 정답 판정하지 않습니다.
발견 당시의 어휘 이해 상태와 현재의 복습 결과는 별도 기록입니다.

‘같은 실수가 줄었는지’ 계산하는 기준
이 풀이 전에 사용자가 확인한 원인·교정 규칙이 저장되어 있어야 합니다.
오답만으로 같은 원인 재발이라고 자동 판정하지 않습니다. 직접 같은 원인이라고 확인해야 합니다.
규칙 적용 확인은 정답 + 힌트 없음 + 확신도 4 이상 + 근거 입력 조건으로 기록합니다.
헷갈림을 체크했거나 예측 품사가 틀린 경우에는 규칙 적용 확인으로 집계하지 않습니다.
같은 문항·같은 주원인의 비교 가능한 복습이 두 번 이상이면 처음과 최근 결과를 비교합니다.
‘다른 원인 / 아직 모름’ 기록은 재발 비율의 분모에서 제외합니다.
C-Test 49개 Task는 원문 문항의 비율과 섞지 않고 별도 비교합니다.
표본이 적으면 전체 실력 개선으로 해석하지 않도록 안내합니다.

새 문제 적용
직접 제작한 신규 연습 28개를 교정 규칙에 연결했습니다. 공식 TPO 문항이 아닙니다.
같은 문항을 여러 번 맞혀도 첫 풀이 성적은 덮어쓰지 않습니다.
발화 기능 연습도 텍스트 이해 훈련이며 원본 음성을 이용한 청취 시험이 아닙니다.
신규 연습 결과를 실제 TOEFL 점수로 환산하지 않습니다.

원본과 최초 시험 성적
TPO2=2026-10-02 / TPO3=2026-10-08 / TPO4=2026-10-12.
고유 오답 63개와 원본 이미지 51장, 지문·스크립트 40개를 보존했습니다.
TPO3-R5 / TPO3-L10은 자료 미확인 상태로 남기고 자동 채점에서 제외합니다.
원본 음성파일은 확인되지 않았습니다. 합성음성·스크립트로 연습합니다.
TPO3 Listening 추가 단독 오답 6개는 분모가 없어 전체 정확도를 계산하지 않습니다.
시험 환경·시간·집중도·체감 난이도는 직접 회고해 입력할 수 있습니다. 기록 없는 값을 채워 넣지 않았습니다.
기존 C-Test 49개 Task의 문단·정답·해설·순서는 원본 저장소와 대조해 모두 유지했습니다.
C-Test 사진 경로는 기존 공개 사이트에서도 404입니다. 사진이 없어도 문단·정답·해설로 연습할 수 있습니다.

백업과 이전 기록
학습 기록 → 기록 백업 내려받기 / 백업 가져오기.
문제 진단·규칙 변경 이력·어휘 내용·어휘 복습·시험 회고·14일 완료 표시까지 포함합니다.
기존 v2 학습 기록을 같은 주소에서 읽고, 연결 데이터가 추가된 v3 구조로 보존합니다.
같은 풀이·어휘 복습·규칙 버전을 중복 집계하지 않고, 더 최근에 수정한 확인 결과를 가져옵니다.
테스트용 학습 기록은 배포 파일에 포함하지 않았습니다.
