TOEFL 통합 학습 사이트 · 2026-10-17

1. 시작하기
Mac: ‘학습 시작.command’를 더블클릭합니다.
브라우저에서 http://127.0.0.1:8871/study/index.html 이 열립니다.
학습하는 동안 함께 열린 터미널 창을 유지하세요. 끝낼 때 창을 닫아도 브라우저 학습 기록은 남습니다.
온라인 배포 후에는 study/index.html을 방문하면 됩니다. 별도 서버 프로그램은 필요 없습니다.
폴더 안 HTML을 각각 직접 열면 브라우저의 파일 저장 정책에 따라 기록 공유가 달라질 수 있으므로 위 시작 파일을 사용하세요.

2. 매일 푸는 순서
① 내 학습의 ‘첫 문제 풀기 / 이어서 풀기’를 누릅니다.
② 읽기: 질문을 읽고 지문에서 근거를 찾은 뒤 답을 고릅니다.
   빈칸: 문장 안 파란 칸에 빠진 철자만 입력합니다.
   삽입: 지문 안 A–D 중 한 곳을 누릅니다.
   듣기: 합성음성 듣기 또는 스크립트 읽기 → 문제 풀기 → 답 고르기.
③ ‘정답 확인하기’를 누른 뒤 근거를 확인하고 ‘다음 문제 풀기’로 이동합니다.
모르면 ‘모르겠어요’를 눌러도 됩니다. 다시 확인 목록에 저장됩니다.

3. 진도와 복습
전체 문제: 코스별 아직 안 품 / 진행 중 / 풀이 완료 / 다시 확인 표시.
학습 기록: 코스별 처음 푼 문제 수, 시도 횟수, 다음 문항, 각 풀이 결과와 시각.
첫 풀이 완료는 한 번 이상 채점했다는 뜻이며, 숙달 판정이나 새 문제 실력 점수가 아닙니다.
오답·스크립트 도움·헷갈림은 다시 확인에 남습니다.
복습 간격은 정답이 이어지면 1일 → 3일 → 7일 → 14일로 늘고, 틀리면 1일로 돌아갑니다.
‘맞혔지만 헷갈렸어요’를 체크하면 맞힌 문제도 다시 확인에 남습니다.
입력·선택·듣기 단계는 자동 저장되며 새로고침 후에도 이어집니다.

4. 기존 C-Test
fillintheblank.html의 기존 49개 Task·문단·정답·해설은 변경하지 않았습니다.
학습 홈에서 같은 페이지로 이동하며 입력·10개 단어 채점·다음 Task 진도를 공유합니다.
C-Test 점수는 Task별 10개 단어, 오답 재풀이는 문항, 약점 교정은 추가 문제로 별도 기록합니다.
기존 C-Test의 원본 사진 경로는 현재 공개 사이트에서도 404이며 저장소에 사진 파일이 없습니다.
사진을 불러올 수 없을 때 안내를 표시하고 문단·정답·해설로 연습할 수 있게 했습니다.

5. 자료와 출처
TPO2=2026-10-02 / TPO3=2026-10-08 / TPO4=2026-10-12.
오답 63개와 원본 이미지 51장을 연결했습니다. 지문·스크립트는 40개입니다.
61개 자동 채점 가능. TPO3-R5, TPO3-L10은 미확인 자료를 보존하고 자동 채점에서 제외했습니다.
원본 음성파일은 확인되지 않았습니다. 합성음성을 원본 음성으로 표시하지 않습니다.
듣기 재풀이 결과를 실제 시험의 듣기 정확도로 환산하지 않습니다.
TPO3 Listening 추가 단독 오답 6개는 분모가 없어 시험 전체 정확도를 계산하지 않습니다.
최초 사용자 답·정답·오류 코드·원인 확실성·출처는 원본 데이터에 보존했습니다.

6. 백업
학습 기록 → 기록 백업 내려받기.
다른 기기·브라우저에서는 같은 화면의 백업 가져오기를 사용합니다.
기존 기록과 합쳐지고 같은 시도는 중복 저장하지 않습니다.
옛 훈련 화면의 같은 브라우저·같은 주소에 저장된 기록은 자동으로 읽습니다.
로컬에서 온라인 사이트로 이동할 때, 또는 주소/포트/브라우저가 바뀔 때는 백업 파일을 옮겨주세요.
테스트용 풀이 기록은 배포 파일에 포함하지 않았습니다.
