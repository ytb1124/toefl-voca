3. 다섯 모듈
A 질문 판단: Target, 보기의 모든 주장에 근거가 있는지, 질문에 답하는지를 별도 판단.
B 대상·특징: 키보드/모바일 선택형 매핑. 독립 풀이/새 적용은 자료를 숨긴 뒤 90초 연결.
C 내용 처리: 합성음성 또는 텍스트 → 회상 → 답 → 막힌 단계 확인 → 선택 문장 재생/스크립트 → 다시 회상.
  WHO/WHAT/WHERE/WHY/NEXT ACTION, Topic/Key Points/Conclusion, 순서 복원을 지원한다.
  한 세션에서는 다음 행동/발화 기능/주제 중 같은 하위 기술을 유지한다.
D C-Test: 제시 철자와 칸 수가 있는 새 문장. Guided 품사·형태·복원·문맥 검증과 Exam 직접 입력을 분리.
E 어휘: mitigate/eliminate, residue/resident, query/complaint, distinction/recognition, acidity/salinity 등 문맥 구별.
  근거 입력은 저장하되 자유 서술의 의미를 자동 채점한 것처럼 표시하지 않는다.
새 연습 43개(이 중 새 문제 적용 21개), 원문/기존 추가 연습과 별도 유형.
정답 배치를 순환하고 각 문항의 근거·모든 선택지·어형을 편집 검토했다.
REVIEWED는 내부 편집 검토이며 외부 공인·심리측정 검증을 의미하지 않는다.
이전 추가 연습 28개는 제거하지 않고, 새 숙련 판정에서는 검토 상태 UNKNOWN으로 제외한다.

4. 데이터 모델과 보존
같은 localStorage 키 taebin-toefl-study-v2를 사용하며 내부 버전을 4로 확장했다.

sessions: 고유 ID, 원문 ID, targetSkillId, 단계, 단계별 입력/회상/힌트/시간, 사용 문항, 완료 시각.

  validationStatus, response, timedLimitMs/timeExceeded, delayedReview, standardDueAt.
stageRecords: 사용자 응답, 단계별 상호작용, 정오 또는 미채점(null), 시간, 도움 사용, 확실성.
원본 문제는 canonical adapter에서 testId/testDate/setId, source/verificationStatus,
  original/reported userAnswer, correctAnswer, passage/transcript, audioUrl=null 등으로 제공한다.
원본 ID/보고서/이미지/답/정답/오류 코드 자체는 변경하지 않았다.
원래 M=Memory 코드와 가이드 M=Meaning 세부 코드를 별도 보존했다.
주원인 수정 시 이후 훈련 기술을 다시 배정한다. 과거 풀이의 기술과 규칙 스냅샷은 덮어쓰지 않는다.
백업 병합은 기존 UID를 중복 추가하지 않고 최신 수정본을 선택한다.

5. 추천·복습·숙련
추천: 사용자 확정 원인, 재발, 최근 신규 실패, 미해결 독립 연습, 복습 기한, 기존 오답 빈도를 사용.
근거가 적으면 '원보고서 기반 제안'으로 표시하며 정확한 실력 점수를 아는 것처럼 수치를 보여주지 않는다.
질문/기술 상태: UNREVIEWED, DIAGNOSED, TRAINING, TRANSFER_PENDING, REVIEW_DUE, MASTERED, RELAPSED.
숙련: 원문 독립 정답 + 검토된 새 문항 첫 독립 정답 + 둘보다 24시간 이상 뒤 정확한 복습.
힌트/헷갈림/품사 오류/시간 초과는 숙련 근거로 인정하지 않는다.
원문 반복 정답만으로 숙련을 부여하지 않는다. 첫 신규 오답은 재풀이 정답으로 덮어쓰지 않는다.
숙련 후 독립 오답은 RELAPSED로 재등록한다. 이는 '같은 원인 재발'을 자동 확정했다는 뜻은 아니다.
동일 원인 재발률은 기존처럼 풀이 전 진단 스냅샷과 사용자의 복습 판단이 있어야 계산한다.
기본 1/3/7/14일, 시험일이 가까우면 압축한다. 날짜 변경은 저장된 복습 기한도 재계산한다.
standardDueAt을 보존해 시험일을 지우거나 늦추면 기본 기한을 복원할 수 있다.
14일 주제를 남은 날짜에 묶고 원문/새 적용/복습 문항으로 연결한다.
독립 평가일·혼합/미니 모의일에는 원문 + 새 적용을 힌트 없이 바로 평가하는 세션을 제공한다.

10. 실제 사용
기존 fillintheblank.html 주소 → 내 학습 → 시험일·훈련 시간 설정 → 오늘의 훈련 시작.
오답을 맞힌 뒤에도 실제 원인을 직접 선택하고 다음 행동을 저장한다.
훈련 후 새 문제에 적용하고, 복습 날짜가 오면 홈에서 이어간다.
성장·복습에서 최초 시험/훈련/신규 적용/지연 유지/재발을 구분해 확인한다.
다른 기기에서는 성장·복습 → 학습 기록·백업으로 옮긴다.
